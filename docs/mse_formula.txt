Mean Squared Error (MSE) — Validation Formula
===============================================

Source: domain/validation_model.py

For each block that has interventions:

  expected_cooling = SUM ( literature_coeff[type] * default_area[type] * count[type] )
                     for each intervention type on that block

  expected_temp = base_temp - expected_cooling

  error = simulated_temp - expected_temp

  squared_error = error^2

Overall MSE across all intervened blocks:

  MSE = (1 / n) * SUM( squared_error )

  where n = number of unique blocks with at least one intervention

--------------------------------------------------
Literature Coefficients (LITERATURE_COEFFS)
--------------------------------------------------
  tree:      0.040 °C/m^2
  greenroof: 0.030 °C/m^2
  leaves:    0.015 °C/m^2

--------------------------------------------------
Default Areas (from CoolingModel.DefaultArea)
--------------------------------------------------
  tree:      43  m^2
  greenroof: 200 m^2
  leaves:    100 m^2

--------------------------------------------------
Example
--------------------------------------------------
Block has: 3 x tree, 1 x greenroof
base_temp = 44.16°C, simulated_temp = 38.35°C

  expected_cooling = (0.040 * 43 * 3) + (0.030 * 200 * 1)
                   = 5.16 + 6.00
                   = 11.16°C

  expected_temp = 44.16 - 11.16 = 39.00°C

  error = 38.35 - 39.00 = -0.65°C

  squared_error = (-0.65)^2 = 0.4225

MSE = average of all squared_errors across all blocks

PASSED if MSE < 1.0, otherwise FAILED.
